# 客户端自动登录

本阶段增加标准登录表单执行器 `engine/login.py`。

## 流程

```text
账号配置
  ↓
启动游戏 EXE
  ↓
发现游戏窗口
  ↓
后端解密密码（仅内存）
  ↓
按窗口相对坐标填写账号/密码
  ↓
点击登录
  ↓
等待并再次检查窗口
```

## 登录控件坐标

由于不同客户端、分辨率、窗口缩放可能不同，项目不写死坐标。
通过环境变量 `MHXY_LOGIN_LAYOUT_JSON` 配置：

```json
{"account":{"x":620,"y":430},"password":{"x":620,"y":470},"login":{"x":760,"y":520}}
```

坐标原点为游戏窗口左上角。

## 安全

- 密码从数据库读取后只在登录执行器内存中短暂存在。
- 日志、API 响应不输出密码。
- 不处理验证码、滑块、短信验证等安全验证；出现此类情况必须暂停并人工处理。
- 生产环境必须配置独立 `MHXY_CREDENTIAL_KEY`。

## 当前限制

`LOGIN_SUBMITTED` 表示登录按钮已提交，并不等价于已经进入角色选择或游戏世界。下一阶段需要通过截图/OCR/模板识别确认：登录成功、角色选择、服务器连接、掉线等状态。
