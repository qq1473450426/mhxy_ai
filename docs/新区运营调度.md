# 新区运营调度与五开同步

本阶段把之前的“练级策略”升级为“每日运营总控”。

## 默认任务优先级

1. 副本三连
2. 师门
3. 抓鬼
4. 周末活动（活动时间内）
5. 新区练级

实际优先级不是固定收益承诺，而是一个可修改的策略参数。后续应使用真实运行数据重新排序。

## 每日次数

- 师门：20
- 抓鬼：30
- 副本三连：1 个运营批次
- 周末活动：按活动 Skill 自己管理次数

这些数字来自当前运营方案的初始配置，不代表游戏服务器当前实际规则；生产环境应允许配置覆盖。

## 五开同步

`TeamCoordinator` 负责：

- 队伍状态统一
- 单账号异常暂停
- 掉线/卡死/窗口异常恢复计划
- 队员重新入队
- 队长异常后的重建队伍计划

它不直接点击游戏，实际动作仍必须经过 Executor。

## 运行原则

每次 `tick()` 只做一次决策或一次执行，避免一个循环无限点击。任务必须返回 `completed=true` 才能增加次数；失败只能标记 `RETRY` 或 `ERROR`，禁止伪造完成。
