# 导航系统说明

本阶段新增 `engine/navigation.py`，把导航规划从任务逻辑中独立出来。

## 当前能力

- 地图路点模型 `MapPoint`
- 路线步骤模型 `RouteStep`
- 按 Skill 路线生成移动步骤
- 判断是否到达目标点
- 注入实际移动执行器
- 后续可替换为 A* 或可通行区域规划

## 为什么暂时不写死坐标

当前仓库没有经过实际客户端标定的截图和坐标数据。直接猜测长安城、师门、抓鬼等坐标会导致自动化误操作，因此本版本只建立导航框架和数据规范。

## 下一阶段

拿到实际客户端截图后：

1. 标定窗口坐标系
2. 建立地图名称模板
3. 建立当前位置识别
4. 采集高频地图路点
5. 建立长安城 → 各门派路线
6. 建立师门任务路线
7. 建立抓鬼路线
8. 将 NavigationPlanner 接入 LevelingController

开发阶段继续保持 Dry Run，确认识别和路线正确后再启用实际输入。
