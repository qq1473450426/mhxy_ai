# 新区练级感知层

本阶段把 `新区快速练级` 从纯策略判断推进到“读取游戏画面”的第一步。

## 当前能力

```text
游戏窗口
  ↓
ScreenLevelingObserver
  ├─ 窗口是否存在
  ├─ 截图
  ├─ 等级 OCR（可选）
  ├─ 经验百分比 OCR（可选）
  ├─ 地图名称 OCR（可选）
  └─ 战斗/任务完成/错误模板识别
```

核心文件：

```text
engine/perception.py
skills/leveling/perception_config.example.json
```

## OCR

Python 层使用 `pytesseract`，但 OCR 引擎本身需要 Windows 安装 Tesseract。

如果暂时不安装 OCR，模板识别仍可以工作；此时 `level_known=False`，练级 Controller 会安全等待，不会因为未知等级执行真实操作。

安装 Python 包：

```bat
pip install pytesseract
```

安装 Tesseract 后，把中文语言包 `chi_sim` 配置好，并确保 `tesseract.exe` 在 PATH 中，或者在 Python 中设置 `pytesseract.pytesseract.tesseract_cmd`。

## 区域标定

复制：

```text
skills/leveling/perception_config.example.json
```

按照实际客户端截图修改区域：

```json
{
  "level_region": [x, y, width, height],
  "exp_region": [x, y, width, height],
  "map_region": [x, y, width, height]
}
```

坐标是**相对于游戏窗口左上角**，不是屏幕绝对坐标。

不要直接把示例坐标当成生产配置。不同分辨率、客户端皮肤和窗口缩放都会导致坐标不同。

## 模板

模板目录建议：

```text
skills/perception/templates/
├── battle.png
├── task_complete.png
└── error.png
```

模板需要从你实际使用的梦幻西游客户端截图裁剪，避免用网上图片代替。

## 只读 API

```text
GET /api/leveling/observe/?account_id=1
```

该接口只进行窗口查找和截图识别，`dry_run=True`，不会点击鼠标和发送键盘输入。

示例返回：

```json
{
  "window_available": true,
  "level_known": true,
  "level": 59,
  "exp_percent": 87,
  "map_name": "长安城",
  "state": "IDLE",
  "template_matches": {}
}
```
