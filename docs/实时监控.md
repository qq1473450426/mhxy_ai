# 五开实时监控

## API

`GET /api/live/`

返回每个账号的运行状态、等级、经验、地图、任务、战斗、重连次数和备用账号切换次数。

## 前端

实时监控页面每 3 秒刷新一次，手机端自动变为单列卡片布局。

## 数据来源

`engine/live_control.py` 提供统一状态缓存。Worker/Perception/重连控制器后续只需要调用 `live_store.update(account_id, ...)` 即可把状态推送到 WebUI。

当前缓存设计为可替换 Redis；生产环境多 Worker 部署时应使用 Redis 或其他共享状态存储，避免不同进程之间状态不一致。
