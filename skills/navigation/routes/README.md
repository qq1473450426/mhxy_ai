# 导航 Skill

这里保存梦幻西游客户端的地图路线数据。

## 数据原则

- 坐标使用游戏客户端实际截图/标定得到的数据。
- 不在代码中硬编码任务逻辑。
- 每条路线只描述地图与路点，不负责领取任务或战斗。
- `engine/navigation.py` 负责读取路线并生成移动步骤。

## 路线格式

建议后续每个地图建立独立 JSON：

```json
{
  "route": "长安城_到_大唐官府",
  "points": [
    {"name": "长安城", "x": 120, "y": 300},
    {"name": "大唐官府入口", "x": 420, "y": 260}
  ]
}
```

> 当前仓库没有真实客户端标定坐标，因此不会伪造坐标数据。拿到实际游戏截图后再建立生产路线。
