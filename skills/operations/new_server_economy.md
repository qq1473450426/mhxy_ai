# 新区经营策略 Skill

> 这是经营决策配置，不是固定收益承诺。实际收益必须通过运行日志、物品/货币变化和耗时统计得到。

## 目标

围绕新区五开建立“升级 + 现金流 + 资源变现”的调度体系。

## 核心活动

| 活动 | 主要目标 | 典型调度 |
|---|---|---|
| 抓鬼 | 经验/稳定产出 | 等级满足后作为主力循环 |
| 副本三连 | 道具/现金/经验 | 每日有限次数优先完成 |
| 师门 | 稳定现金/经验 | 每日固定次数 |
| 周末活动 | 限时高价值 | 根据活动时间窗口提升优先级 |
| 活力变现 | 将闲置活力转成资源 | 与生产/采集技能状态联动 |
| 打宝图 | 单人现金流 | 只在角色等级和成本满足条件时执行 |
| 商业倒卖 | 资金利用 | 需要独立的库存、成本、成交价记录 |

## 决策原则

1. 不使用“每天必赚 X 元”作为自动化条件。
2. 使用真实运行数据计算每小时净收益。
3. 先保证现金流，再考虑低频高波动玩法。
4. 限时活动在窗口内自动提升优先级。
5. 当风险、失败率或资金占用超过阈值时暂停该活动。
6. 练级目标与经营目标冲突时，由上层策略指定权重。

## 必须采集的数据

- 活动开始/结束时间
- 获得经验
- 获得游戏币
- 获得物品及数量
- 消耗游戏币
- 活动失败次数
- 实际耗时
- 角色等级变化

## 五开策略

默认队伍结构为：

```text
1 名队长/辅助 + 4 名输出
```

队长负责任务推进，队员保持跟随和状态同步。具体门派和角色配置不要硬编码，应从账号配置读取。
