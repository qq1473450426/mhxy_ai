# 梦幻西游新区快速练级 Skill

> 中文策略 Skill。用于根据角色等级、目标等级、队伍规模和当前可执行任务，选择当前阶段优先级最高的练级任务。
>
> 本 Skill 只描述任务策略和执行条件，不包含协议封包、进程注入或反作弊绕过。

## 1. Skill 标识

```yaml
name: 新区快速练级
id: new_server_fast_leveling
category: leveling
language: zh-CN
mode: strategy
```

## 2. 输入状态

建议由 Worker / TaskRunner 提供以下字段：

```yaml
level: 0                 # 当前角色等级
exp_percent: 0           # 当前等级经验百分比
target_level: 69         # 目标等级
team_size: 5              # 队伍人数
is_leader: true           # 是否队长
has_daily_tasks: true     # 是否仍有主要日常任务
has_instance: true        # 当前阶段是否存在可执行副本
has_ghost_task: true      # 当前阶段是否可以抓鬼
server_age_days: 0        # 新区开启天数，可选
```

## 3. 阶段策略

### 0～19级：快速脱离新手阶段

优先级：

1. 新手/主线任务
2. 师门任务
3. 系统开放引导

策略说明：

- 以主线和等级解锁为第一目标。
- 不建议为了低收益重复战斗。
- 新任务出现时优先完成能够解锁后续玩法的任务。

### 20～29级：主线 + 师门

优先级：

1. 主线/等级解锁任务
2. 师门
3. 当前可完成的活动

策略说明：

- 优先保持角色等级满足下一批任务的开放条件。
- 避免长距离、低经验收益任务反复执行。

### 30～39级：进入稳定刷经验阶段

优先级：

1. 抓鬼
2. 师门
3. 副本/活动
4. 主线补缺

策略说明：

- 队伍稳定后，以连续经验任务为核心。
- 单次任务准备时间过长时，优先选择可立即连续执行的任务。

### 40～49级：提高单位时间经验

优先级：

1. 抓鬼
2. 副本
3. 活动
4. 师门
5. 主线补缺

策略说明：

- 优先连续执行高经验、低移动成本任务。
- 队伍不足时允许切换到单人可执行任务，避免空转等待。

### 50～59级：冲击60级

优先级：

1. 抓鬼
2. 副本
3. 活动
4. 师门
5. 其他高经验任务

策略说明：

- 以到达60级为短期目标。
- 如果距离升级只差少量经验，优先选择能快速完成的短任务。

### 60～69级：冲击69级

优先级：

1. 抓鬼
2. 副本/高经验活动
3. 师门
4. 短周期经验任务

策略说明：

- 默认目标为69级。
- 接近69级时，优先选择稳定、短周期、低失败率任务。
- 达到69级后停止自动升级任务，并进入卡级策略等待人工确认。

## 4. 动态选择规则

不要把路线理解成固定脚本。每次执行前重新计算候选任务。

推荐评分：

```text
score =
    exp_weight * estimated_exp
  - travel_weight * estimated_travel_seconds
  - failure_weight * failure_risk
  + chain_bonus * repeatability
  + unlock_bonus * unlock_value
```

推荐默认权重：

```yaml
exp_weight: 1.0
travel_weight: 0.25
failure_weight: 2.0
chain_bonus: 1.5
unlock_bonus: 2.0
```

## 5. 安全约束

以下情况不得直接执行危险动作：

- 游戏窗口不存在
- 当前角色状态无法识别
- 任务前置条件不满足
- 连续失败达到重试上限
- 账号处于 DISCONNECTED / ERROR
- Skill 未找到

发现异常时，应记录日志并返回安全状态，由 Worker 决定重连或等待人工处理。

## 6. 队伍策略

### 5开

默认优先：

```text
队长执行任务选择
        ↓
队员同步任务阶段
        ↓
队长导航
        ↓
队员跟随
        ↓
共同战斗
        ↓
校验队伍状态
```

### 单开/非满队

如果队伍等待时间超过配置阈值，应允许切换至当前可执行的单人任务，避免长期空闲。

## 7. 任务完成判断

任务只有同时满足以下条件才认为成功：

1. 游戏状态从执行态返回稳定态。
2. 任务目标或任务日志发生变化。
3. 能够识别奖励/经验变化，或检测到明确完成标志。

如果只检测到点击成功，不能直接判定任务完成。

## 8. 重试策略

```yaml
max_retry: 3
retry_delay_seconds: 2
relocalize_after_failure: true
reselect_task_after_failure: true
```

连续失败时：

```text
执行失败
  ↓
重新识别
  ↓
重新定位
  ↓
重试
  ↓
仍失败 → 换候选任务
  ↓
全部失败 → ERROR / 人工处理
```

## 9. 推荐任务关键字

TaskRunner 当前通过 SkillStore 关键词匹配 Skill，因此建议任务名包含以下中文关键字：

- 新区快速练级
- 抓鬼
- 师门
- 副本
- 活动
- 主线
- 69级

## 10. 当前实现边界

本 Skill 是策略层配置，不硬编码具体地图坐标和客户端按钮位置。

地图、坐标、模板应继续放在：

```text
skills/maps/
skills/navigation/
skills/battle/
```

这样客户端分辨率或地图变化时，不需要修改练级决策算法。
